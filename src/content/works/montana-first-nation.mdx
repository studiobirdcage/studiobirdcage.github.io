After the completion of the <a href="/works/alexis-nakota-sioux-nation">Alexis Nakota Sioux Nation</a> project, I was tasked with a very similar project for the Montana First Nation band office. They had very similar requirements to the ANSN project. Montana First Nation's old site had been built on supremely outdated software (I believe it was built half in Flash and the other half with tables) nearly eight years ago, and they wanted a new site that was modern, responsive, and fast.

Using the Gulp setup I had built for the ANSN project made development on this site a breeze. I was able to leverage all of the features without having to write a new Gulp file. In a competitive industry like web development, where the hours can really stack up quickly, any advantage to the development process that cuts time and cost is very welcome.
