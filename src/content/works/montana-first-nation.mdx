After the completion of the <a href="/works/alexis-nakota-sioux-nation">Alexis Nakota Sioux Nation</a>, I was tasked with a very similar project for the Montana First Nations band office. They had very similar requirements to the ANSN project. Montana First Nation's old site had been built on supremely outdated software (I believe it was built half with flash and the other half with tables) nearly 8+ years ago and they wanted a new site that was modern, responsive and fast.

Using the Gulp setup I had built from the ANSN project made development on this site a breeze. I was able to leverage all of the features without having to write a new gulp file. In a competitive industry like web development where the hours can really stack up quickly, any advantage to the development process that cuts time and cost is very welcome.
